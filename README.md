# Boora

Site e app do Boora: um personal trainer com IA para quem quer evoluir na academia. Treino, corrida, caminhada e bike,
alimentação sem trabalho manual, água e descanso, num app só.

Este repositório publica o site pelo GitHub Pages. No começo, o site é o próprio app, feito para usar no celular e no
iPad e instalar na Tela de Início.
