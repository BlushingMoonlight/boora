# Fontes

Fontes de código aberto, servidas pelo próprio site (sem depender de serviço de fora). Todas sob a SIL Open Font
License 1.1; o texto de cada licença está em `licencas/`. Arquivos do subconjunto latino (inclui os acentos do
português), em versão variável (`wght`), vindos dos pacotes `@fontsource-variable` do npm.

| Arquivo | Fonte | Licença |
| --- | --- | --- |
| `inter-latin-wght-normal.woff2` | Inter | OFL 1.1 |
| `figtree-latin-wght-normal.woff2` | Figtree | OFL 1.1 |
| `manrope-latin-wght-normal.woff2` | Manrope | OFL 1.1 |
| `plus-jakarta-sans-latin-wght-normal.woff2` | Plus Jakarta Sans | OFL 1.1 |
| `space-grotesk-latin-wght-normal.woff2` | Space Grotesk | OFL 1.1 |

Nesta etapa, as fontes servem só para comparar as três direções (`prototipo/direcoes/`). Depois que o Jean escolher,
ficam só as da direção escolhida.
